CreateUIContext

CreateUIContext (renderer: ^Renderer.RenderContext, mouse_data: ^EventSys.Mouse)

creates a new UIContext to use for ui state

Parameters:
  • renderer: a pointer to the renderer's RenderContext you want to render to
  • mouse_data: a pointer to the mouse data returned by the event system every frame
Returns: a pointer to the new UIContext

DestroyUIContext

DestroyUIContext (ctx: ^UIContext)

deletes a UIContext

Parameters:
  • ctx: a pointer to the UIContext you want to delete

Button

Button (
	ctx: ^UIContext,
	pos, size: Types.Vector2f,
	color, pressed_color: Types.Color,
	r_click: bool = false,
) -> bool

renders a button to the renderer in ctx

Parameters:
  • cxt: a pointer to the UIContext to use for state and rendering
  • pos: the position on the screen to render the button
  • size: the size of the button
  • color: the color of the button
  • pressed_color: the color of the button when pressed
  • r_click: wether to respond to a right click (true) or a left click (false)
Returns: a bool indicating if the button was pressed or not

CheckBox

CheckBox (
	ctx: ^UIContext,
	pos, size: Types.Vector2f,
	value: ^bool,
	check_texture, uncheck_texture: ^Renderer.Texture,
) -> bool

renders a check box to the renderer in ctx

Parameters:
  • ctx: a pointer to the UIContext to use for state and rendering
  • pos: the position on the screen to render the check box
  • size: the size of the hitbox for the checkbox
  • value: a pointer to a bool used to store the current state of the checkbox over time
  • check_texture: the texture to display when the check box is checked
  • uncheck_texture: the texture to display when the check box is unchecked
Returns: a bool representing the state of the check box this current frame

UnsignedIntegerSlider

UnsignedIntegerSlider (
	ctx: ^UIContext,
	pos, size: Types.Vector2f,
	value: ^u64,
	min_max: [2]u64,
	step_size: u64,
	bar_color: Types.Color,
	slide_color: Types.Color,
) -> u64

renders a slider that uses an unsigned integer for the value

Parameters:
  • ctx: a pointer to the UIContext to use for state and rendering
  • pos: the position on the screen to render the slider
  • size: the size of the slider (this is the bar size as the slide size is calculated from this)
  • value: a pointer to a u64 used to store the current state of the checkbox over time
  • min_max: an array of two values the first value is the minumum value for the slider and the second value is the maximum value of the slider
  • step_size: this is the value that the value steps by when the slider is moved
  • bar_color: the color of the bar that the slider is atatched to
  • slide_color: the color of the slider
Returns: a u64 representing the state of the slider this current frame

YesNoDialog

YesNoDialog (
	title: string,
	text: string,
	type: MessageBoxType,
	background_color    := [3]u8{255, 255, 255},
	text_color          := [3]u8{0, 0, 0},
	button_border_color := [3]u8{0, 0, 0},
	button_color        := [3]u8{255, 255, 255},
	button_select_color := [3]u8{191, 191, 191},
) -> bool

a dialog box with text and a yes or no option

Parameters:
  • title: the title for the dialog window
  • text: the text for the dialog window
  • type: the type of message box. Options: (ERROR, WARN, INFO)
  • background_color: the background color of the dialog
  • text_color: the text color of the dialog
  • button_border_color: the color of the border of the buttons
  • button_color: the color of the buttons
  • button_select_color: the color of the button when it is selected
Returns: a bool signifying yes: true or no: false
