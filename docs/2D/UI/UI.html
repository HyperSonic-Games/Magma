CreateUIContext

CreateUIContext (renderer: ^Renderer.RenderContext, mouse_data: ^EventSys.Mouse)

creates a new UIContext to use for ui state

Parameters:
  • renderer: a pointer to the renderer's RenderContext you want to render to
  • mouse_data: a pointer to the mouse data returned by the event system every frame
Returns: a pointer to the new UIContext

DestroyUIContext

DestroyUIContext (ctx: ^UIContext)

deletes a UIContext

Parameters:
  • ctx: a pointer to the UIContext you want to delete

Button

Button (
	ctx: ^UIContext,
	pos, size: Types.Vector2f,
	color: Types.Color,
	pressed_color: Types.Color,
	r_click: bool = false,
) -> bool

renders a button to the renderer in ctx

Parameters:
  • ctx: a pointer to the UIContext to use for state and rendering
  • pos: the position on the screen to render the button
  • size: the size of the button
  • color: the color of the button
  • pressed_color: the color of the button when pressed
  • r_click: wether to respond to a right click (true) or a left click (false)
Returns: a bool indicating if the button was pressed or not

CheckBox

CheckBox (
	ctx: ^UIContext,
	pos, size: Types.Vector2f,
	value: ^bool,
	check_texture, uncheck_texture: ^Renderer.Texture,
) -> bool

renders a check box to the renderer in ctx

Parameters:
  • ctx: a pointer to the UIContext to use for state and rendering
  • pos: the position on the screen to render the check box
  • size: the size of the hitbox for the checkbox
  • value: a pointer to a bool used to store the current state of the checkbox over time
  • check_texture: the texture to display when the check box is checked
  • uncheck_texture: the texture to display when the check box is unchecked
Returns: a bool representing the state of the check box this current frame
